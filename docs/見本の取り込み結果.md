## 見本から変えた所

| 変えた所 | 理由 |
|---|---|
| 「補助の形」「上限額_円」「補助率」の列を足した | 毎月の補助と1回きりの補助を取り違えないため。金額を数として使えるようにするため。値は見本の「金額」「備考」から起こした |
| 「確認できず」の2件(福岡市、北九州市)は、出典URL を「探した場所」に移した | 見つからなかったページは、制度の出典ではないため |
| 古賀市の利用料補助: 「開始」にあった要綱の制定日を、備考へ移した | 制定日は開始の時期ではない。開始の時期は確かめていないので空にした |
| 大野城市の一覧: 「開始」にあった「現在の一覧」の日付を、備考へ移した | 同じ理由 |
| id `40219-shusseki-list` を `40219-shusseki` にした | 種類の名前とそろえた |
| 「要綱」を「要綱の状況」と「要綱URL」に分けた | 要綱の URL そのものは、見本に入っていなかった。4件とも URL は未取得 |
| 確認方法を「機械の読み取り」にそろえた | 人の再確認は、12件ともまだ |
