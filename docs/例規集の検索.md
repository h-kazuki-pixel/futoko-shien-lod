# 例規集の検索(人と Muse がブラウザで探すとき)

弱い所15の続き。11/17 にこちらの読み取りの道具で例規集を探したが、業者のサイトや検索の画面だけのサイトは読めなかった。そこを、人のブラウザか Muse で探す。

## 探すもの

都市圏の「確認できず」のマスのうち、例規集に載りうるもの。

| 種類 | 例規集での形 | 例 |
|---|---|---|
| 出席扱いの要綱(shusseki) | 要綱・要領 | 「不登校児童生徒が民間施設において相談・指導を受けている場合の指導要録上の出欠の取扱い」(那珂川市の要綱の名前に近い) |
| 利用料の補助(fs-hojo) | 補助金交付要綱 | 「フリースクール等利用児童生徒支援補助金交付要綱」(古賀市) |
| 教育支援センター(shien-center) | 設置条例・設置規則・運営要綱 | 「適応指導教室設置規則」「教育支援センター運営要綱」 |
| オンライン(online) | まれ。要綱があることもある | 「オンライン学習支援」 |

**気をつけること:** 例規集によっては、条例と規則だけを載せ、要綱を載せていない。例規集に無くても、制度が無いとは言えない。「確認できず」のままにし、探した場所に足すだけにする。

## 引く言葉

次の順に引く。1つ引いたら結果を控えてから次へ。

1. 不登校
2. 適応指導
3. 教育支援センター
4. フリースクール
5. 出欠 (指導要録上の出欠)
6. 居場所
7. オンライン

## 控えること(1件見つかるごと)

本文は写さない。次だけを控える。

- 市町、引いた言葉
- 例規の名前(題名そのまま)
- 制定日と番号(例: 令和7年3月31日 教育委員会告示第2号)、最終改正日
- その例規のページの URL。検索の画面の URL ではなく、例規そのものを開いたときのアドレス。サイトに「このページのURL」「リンク」のボタンがあれば、その URL
- 分かる範囲で: 対象、金額(補助なら上限)、申請の時期

見つからなかったときも控える: 市町、引いた言葉、日付、「0件」。要綱を載せていない例規集なら、そのことも。

## 見つかったあと(チャットでやること)

- URL が市町の公式ドメインでなければ、出典に使う前に、市町の公式サイトからリンクされていることを確かめ、`data/koushiki_domain.csv` に根拠つきで足す(ドメインごとではなく、その市町の場所に限って足せるよう、仕組みも直す)
- 業者のサイトは、照合のプログラムが取得できない恐れがある。そのときは、人が確かめた行として扱う(`確認方法` を「人の再確認」にし、項目を人が見比べる)
- Muse の報告は手がかりで、人が確かめたことにはならない(弱い所25)。「あり」にする前に、人かこちらが例規のページを開いて見比べる

## 結果(2026-11-17)

Muse が10市町の例規集を下調べし(全文検索は筑紫野市・志免町だけ。ほかは題名か目次)、こちらでリンク元と中身を確かめた。

| 市町 | 見つかったもの | 扱い |
|---|---|---|
| 宇美町 | 教育支援センター設置要綱(くすのき教室) | 公開した(照合で一致。センターは確認できず → あり) |
| 志免町 | 教育支援センター設置要綱(さくらのみち、令和8年7月) | 公開した(照合で一致。同上) |
| 篠栗町 | 教育支援センター設置要綱(適応指導教室を置く) | 公開した。例規集のサイトの robots.txt が HTTP 403 で機械では取得しないので、橋本がブラウザで見比べた(11/17、全項目合っている) |
| 春日市 | 不登校児童生徒の指導要録上の出席の取扱いに関する要綱 | 同上。施設の一覧は例規のページに無かった(データの備考と同じ) |
| 筑紫野市・福津市・糸島市 | 教育支援センターの規則・条例 | センターは既に「あり」。データは変えない |
| 宗像市・粕屋町・久山町 | 該当なし | 「確認できず」のまま |

- 利用料の補助(保護者向け)とオンラインの要綱は、10市町すべてで見つからなかった。例規集の多くは全文検索ができず、題名で見ただけなので、本文の中の定めまでは分からない
- 業者のサイトの例規集は、市町の公式サイトからリンクされていることを確かめ、その市町の場所だけを `data/koushiki_domain.csv` に足した(春日市・篠栗町・宇美町・志免町)
- 篠栗町と春日市の中身は、こちらの読み取りの道具でも開けなかった。橋本がブラウザで見比べてから公開した。照合(`shougou`)ではこの2行は今後も「取得できず」と出る
