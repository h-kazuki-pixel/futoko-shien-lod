# 定期的な取り直し

制度は変わる。出典のページが変わったのに、データが古いまま残るのを防ぐ。作るのは `futoko_lod/torinaoshi.py`、回すのは GitHub Actions の `torinaoshi`(毎週 月曜 13:24、日本時間。11/16 に 13:23 から変えた。手でも起動できる)。

## やること

| 対象 | やること |
|---|---|
| 「あり」「予定」と、出典のある「なし」 | 出典のページを取り直し、`shougou` と同じ照合をする |
| 「確認できず」 | 探した場所のページを取り直す。制度が載ったかもしれないページを、見逃さないため |
| どちらも | 前回の記録と比べ、変わった所を1行ずつ残す |

公開データ(`data/seido.csv`)は書き換えない。直すかどうかは、人が出典を見て決める。

## 残すもの

| ファイル | 中身 |
|---|---|
| `data/torinaoshi/saishin.csv` | いちばん新しい取り直しの結果。行(id)とページ(URL)の組ごとに1行。取得日時、取得できたか、照合の判定、本文の印、照合で見たもの、合わなかったもの、種類の語の数 |
| `data/torinaoshi/sabun.csv` | 変わった所。足していくだけで、消さない |

ページの本文は残さない。「本文の印」は、文字列の空白や全角半角をそろえてから取った印(SHA-256 の先頭16文字)で、変わったかどうかだけが分かる。

## 何が変わったか(11/17。弱い所 取2)

本文を残さないまま、「何が変わったか」を少しでも言えるように、毎回つぎの3つを残す。どれもデータの側の語句・数字か、決めた語の数で、ページの文は入らない。

| 列 | 中身 | 例 |
|---|---|---|
| 照合で見たもの | 出典(第2の出典)との照合で見た項目。根拠の箇所と、金額・対象・開始・上限額・補助率の数字(人が読める形)。備考の数字(指定年など)は「備考の2026年」の形で、備考を裏付ける出典の行に付ける(`shougou` と同じく、出典と第2の出典のどちらかにあればよい。両方を取得できたときだけ見る)。「なし」の行は、根拠の箇所・市町村が管理する学校の印が無いこと・県名+市町村名が無いこと | `根拠の箇所 \| 1/2 \| 10000円` |
| 合わなかったもの | 照合で見たもののうち、ページに見つからなかったもの。空なら全部あった | `10000円` |
| 種類の語の数 | 探した場所のページに、種類の語が何回出たか。語は「フリースクール」「民間施設」「教育支援センター」「適応指導教室」「学びの多様化学校」「不登校特例校」「オンライン」「メタバース」「出席扱い」 | `オンライン:2 \| 出席扱い:0 …` |

変わった所(`sabun.csv`)への書き方:

| 起きたこと | 重さ | 前 → 後 の例 |
|---|---|---|
| 照合が一致から不一致になった | 要確認 | `一致` → `不一致(合わない: 根拠の箇所 \| 10000円)` |
| 前回は見なかったもの(データを直した、前回は第2の出典が取れず備考の数字を見なかった)が、今回は合わない | 記録のみ | `見ていない` → `備考の2026年` |
| 不一致から一致に戻った | 記録のみ | `不一致(合わない: 1/2)` → `一致` |
| 不一致のまま、合わないものが変わった | 記録のみ | `1/2` → `根拠の箇所 \| 10000円` |
| 文字は変わったが、照合で見た語句と数字はすべてまだある | 記録のみ | 本文の印(前と後) |
| 「確認できず」の行の探した場所で、その行の種類の語が増えた(0回から出たときも、もともと出ていて増えたときも) | 要確認 | `オンライン:0` → `オンライン:1`、`オンライン:2` → `オンライン:3` |
| 探した場所で、種類の語の数が変わった(上以外。減ったとき、ほかの種類の語のとき) | 記録のみ | `出席扱い:2` → `出席扱い:1` |

限界: 本文を残さないので、照合に使っていない所(手続きの説明、問い合わせ先など)のどの文が変わったかは分からない。種類の語が出ても、制度が載ったのか、関係の無いお知らせなのかは、人が見るまで分からない。語の数は、メニューやお知らせの欄の出入りでも変わる。前回と今回は、両方の回で見たものだけを比べる。データの側(`seido.csv`)を直したときや、第2の出典が取れずに備考の数字を見なかった回があっても、取得の成否のたびに要確認が繰り返し出ないようにするため。種類の語の数も、両方の回で数えた語だけを比べる(語を足した回に「増えた」と言わない)。備考の数字は、出典と第2の出典のどちらかのページの**どこかに**あるかを見るだけで、学校の行の近くにあるかは見ていない。ページのほかの所(更新日、ほかの学校の行)に同じ年があれば、学校の行が消えても一致のまま。種類の語は、ページ全体で数えるので、メニューにある語が1回増えただけでも要確認になりうる(人が見て、制度が載ったかを決める)。この形になる前の記録(11/16 まで)とは、新しい列を比べない。

## 変わった所の重さ

| 重さ | 何が起きたか | どうなるか |
|---|---|---|
| 要確認 | 照合が一致でなくなった。出典を取得できなくなった(間をあけて2回試し、2回とも)。「確認できず」の行の探した場所に、その行の種類の語が新しく出た | Issue で知らせる |
| 記録のみ | ページの文字が変わったが、照合は一致のまま。合わない語句・数字が変わった(不一致のまま)。探した場所のページの文字や、種類の語の数が変わった。取得できるようになった | `sabun.csv` に残すだけ |

前回の記録に無い行(新しく足した行)は、変わった所に数えない。同じページを出典にする行が多いとき(文部科学省の一覧など)、文字の変化はページごとに1行にまとめる。

## 初回の結果(2026-11-15 19:30 UTC、実行 43752808893)

数え方: 出典と探した場所の URL を、重なりを1つにして数えた。

| | 件数 |
|---|---|
| 取りに行ったページ | 41 |
| うち 取得できた | 39 |
| うち 取得できなかった | 2 |
| 出典と照合した行 | 80(一致 77、不一致 0、取得できず 3) |

取得できなかった2ページは、どちらも福岡市のサイト(`soudan04.html` と `kyouikusiencenter.pdf`)で、2回とも HTTP 404 だった。この2ページは、前日(11/14 20:07 UTC)の `shougou` では取得でき、照合も一致していた。ページが無くなったのか、夜中の保守なのか、たまたまなのかは、まだ分かっていない。初回なので比べる相手が無く、変わった所としては記録されていない。

## 分かっていないこと

- 「探した場所のページの文字が変わった」が、毎週どれくらい出るか。日付や件数が載るページは、中身が同じでも毎回変わるかもしれない。2〜3回まわしてから、知らせに入れるかを決める
- 画像だけの PDF、robots.txt で止まるサイトは、取り直しても変化が分からない(須恵町は 11/15 に止まっていたが、11/16 夜は robots.txt が無く取得できた)
- ページの場所が替わったとき(年度入りの資料)、新しい場所は探さない。「取得できなくなった」と知らせるまで

## 予定の時刻を変えるとき(11/16)

`.github/workflows/torinaoshi.yml` の `cron` の行は、橋本のアカウントで GitHub の画面から変える。作業環境から push したコミットは GitHub の上で「claude」というアカウントの作になる。予定の実行は cron の行を最後に変えた人に結び付くので、そのアカウントが最後だと走らないことがある(解説記事による。GitHub の公式文書では確かめていない)。11/16 は、cron の行を最後に変えたのが「claude」のコミット(465a629)で、予定の実行は一度も記録されていなかった。cron 以外の行は、作業環境から変えてよい。11/16 18時台に、橋本が画面から cron の行を 13:24 に変えた(コミット d544f77、GitHub の上で h-kazuki-pixel の作)。
