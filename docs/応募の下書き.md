### 作品の概要説明(案)

不登校の子どもと保護者が使える公的な支援は、市町村ごとに違います。このデータは、福岡県の市町村について、フリースクール等の利用料の補助、教育支援センター、学びの多様化学校、オンラインの支援、出席扱いの要綱の5種類を同じ項目で並べ、1件ごとに公式の出典と確認日を付けたものです。

いちばんの特徴は、「制度なし」と「確認できず」を混ぜないことです。公式サイトに記載が無いとき、制度が無いのか、載っていないだけなのかは分かりません。このデータでは、市町村の回答か公式の一覧で確かめられたものだけを「なし」とし、見つからなかっただけのものは「確認できず」として、探したページの URL を残します。

「あり」の行は、金額や対象に出てくる数字が出典のページに実際にあるかをプログラムで照合し、合わない行は公開しません。週に1回、出典のページを取り直し、変わった所を記録します。

133件(あり・予定 26、なし 55、確認できず 52)を、CSV、JSON-LD、Turtle で公開しています。1件ごとに URI があり、市町村は e-Stat 統計LOD の標準地域コードにつないでいます。無い・分からないという記録を、制度として数えさせないよう、型を分けています。分かっていないことも、作品のページに書いています。

## URL の選び方

フォームの URL は、審査する人が最初に開くページ。入口の表(`/`)は保護者向けで、作品の説明が無い。そこで「この作品について」(`about/`)を作った。課題、いまの中身(数はデータから数える)、正しさを保つ仕組み、使い方、分かっていないことが1ページで読める。表・データ・リポジトリへは、そこから行ける。

## 送るまでにやること

1. 問い合わせの回答を入れ、「確認できず」を減らす(いちばん効く)
2. 人の再確認を進め、誤りの割合を出す
3. つながる可能性: 組み合わせの例は作った(下)。ほかの人に使ってもらう当てを探す
4. 応募者名と所属を決める
5. テーマ賞は、公式サイトのどのページにも中身の記載が無かった(11/16)。発表されたら見る
6. 送る直前に、概要説明の数を `about/` に合わせる。送った後は、1/5 まで中身を直せる

## つながる可能性について(11/16 に決めた)

観点の説明は「複数のデータの組み合わせが提案され、ほかの作品などで利用・実現されているか」。

- **「わたしの学校2050」には入れない(橋本、11/16)。** 主題(児童数の将来を小学生が予想する授業用のアプリ)と合わず、向こうは全国、こちらは福岡県だけ。UDC の作品を、こちらの都合で曲げない。「わたしの学校2050」は UDC だけに出し、LODチャレンジのデータ活用部門には出さない
- **代わりに、こちらの側に組み合わせの実例を置いた。** `kumiawase/` のページ。標準地域コードの URI を手がかりに、e-Stat 統計LOD の小学校児童数・中学校生徒数を実際に引き、17市町の制度の確かめ具合と並べた。問い合わせ(SPARQL)と、つなぎ方の手順も載せた
- 示せるのは観点の前半(組み合わせの提案と、その実現)まで。**ほかの人の作品で使われた事実は、まだ無い。** 応募文には、そう書く
- 弱い所: 児童数・生徒数は2015年の値。並べただけで、そこから言えることはまだ無い
- 那珂川市は、いまのコードに値が無く、前の那珂川町のコードから取れた(11/16。17市町すべてで値が返った)
- 別の目での点検(11/16)を受けて、公開データの `areaServed` の URI から出発する形に直した。点検の結果は `docs/公開の形.md` の末尾
