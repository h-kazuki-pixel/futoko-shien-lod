### 作品の概要説明(案)

不登校の子どもと保護者が使える公的な支援は、市町村ごとに違います。このデータは、福岡県の市町村について、フリースクール等の利用料の補助、教育支援センター、学びの多様化学校、オンラインの支援、出席扱いの要綱の5種類を同じ項目で並べ、1件ごとに公式の出典と確認日を付けたものです。福岡都市圏の17市町は5種類すべてを調べ(85マスのうち84マスに状態が付き、あり 26、なし 14、確認できず 44)、県内のほかの市町村は学びの多様化学校を並べました。

いちばんの特徴は、「制度なし」と「確認できず」を混ぜないことです。公式サイトに記載が無いとき、制度が無いのか、載っていないだけなのかは、ページからは分かりません。このデータでは、市町村の回答か公式の一覧で確かめられたものだけを「なし」とし、見つからなかっただけのものは「確認できず」として、探したページの URL を残します。いまの「なし」は、すべて学びの多様化学校で、文部科学省の一覧に載っていないことによるものです。市町村が無いと答えた「なし」は、まだありません。「確認できず」のマスは、市町村への問い合わせ(都市圏17市町すべてに送った)で減らしている途中で、問い合わせた行には日付を、すべての行には隣の市町村の同じ種類の状態を付けています。

「あり」の行は、出典の URL・根拠の語句・確認日がそろわないと保存できません。金額・対象・時期と備考に出てくる数字が、出典のページに実際にあるかをプログラムで照合し、合わない行は載せません。根拠が2つの資料に分かれる制度は、2つ目の出典も持ち、両方で照合します。人も出典と見比べています(「あり」「予定」の行の147項目のうち108項目。違いは0。2026-11-17 時点。送る前に about/ の数に合わせる)。

出典と探した場所のページを週に1回取り直し、変わった所を記録する仕組みを置いています。ページの本文は保存せず、照合に使う語句と数字の一つ一つがページにまだあるかを残すので、出典が変わったときに、何が合わなくなったかが分かります。取り直し、人の見比べ、市町村への問い合わせは、1件ごとの「確かめた記録」として RDF(PROV-O)でも公開しています。

全体は133件(あり・予定 33、なし 55、確認できず 45)で、CSV、JSON-LD、Turtle で公開しています。1件ごとに URI があります。公開する RDF が守る決まり(状態ごとの必須の項目、公式サイトの出典など)は SHACL の形として公開し、公開のたびにこの形で検査して、外れれば公開しません。市町村は e-Stat 統計LOD の標準地域コードと DBpedia Japanese につなぎ、統計LOD の児童数・生徒数と並べた例と、DBpedia Japanese の「隣接自治体」で隣の市町村と並べた例を作りました。項目は、デジタル庁の「行政サービス・制度」のデータモデル(GIF)と欧州の CPSV-AP に対応表を付けています。無い・分からないという記録を制度として数えさせないよう、型を分けています。分かっていないことも、作品のページに書いています。版ごとの中身は Zenodo に保管しています(DOI 10.5281/zenodo.24292049)。

## URL の選び方

フォームの URL は、審査する人が最初に開くページ。入口の表(`/`)は保護者向けで、作品の説明が無い。そこで「この作品について」(`about/`)を作った。課題、いまの中身(数はデータから数える)、正しさを保つ仕組み、使い方、分かっていないことが1ページで読める。表・データ・組み合わせの例・語彙・リポジトリへは、そこから行ける。

## 書ける言い方・書けない言い方

- 人の見比べ: 「人が108項目を出典と見比べ、違うは0」と、母数(147項目)を添えて書く(数は 2026-11-17 時点。送る前に about/ に合わせる)。「誤り率0%」「人が全件を確かめた」は書けない(文書105)。見比べたのは橋本1人で、データを作った側でもある
- 照合: 「ページに無い数字を載せていない」まで。数字の意味の取り違えは、照合では見つからない
- 「なし」55件は、すべて学びの多様化学校で、文部科学省の一覧に載っていないという意味。市町村が無いと答えた「なし」は、まだ0件
- 隣で「あり」でも、こちらにあるとは言えない。探す順番の目安にとどめる
- 取り直し: 「週に1回取り直す仕組み」とは書けるが、「毎週回っている」は、11/23 に確かめるまで書けない。「何が合わなくなったかが分かる」は、照合に使う語句と数字までの話。ページのどの文が変わったかは分からない
- 形(SHACL): 「公開のたびに SHACL の形で検査している」「SHACL Core だけで書いた」とは書ける。「どの道具でも同じ結果になる」は書けない(確かめたのは pySHACL だけ)
- 照合: 「合わない行は載せない」は、載せるときの決まり。いま福岡市の出典3行は、市のサイトが 404 で取り直しの照合ができていない(載せたときは一致していた)。「公開中の全行がいま照合に通っている」とは書けない
- 範囲: 5種類すべてを調べたのは都市圏17市町だけ。ほかの市町村は学びの多様化学校だけ(県の行には、施設の設置者向けの補助も1件ある)。「県内の全市町村で5種類」と読める書き方をしない
- 問い合わせ: 都市圏17市町すべてに送った(福岡市は 11/17)。「確認できず」のうち、問い合わせの記録が無いのは北九州市の利用料の補助(都市圏の外)。送る直前に数え直す

- 示せるのは観点の前半(組み合わせの提案と、その実現)まで。**ほかの人の作品で使われた事実は、まだ無い。** 応募文には、そう書く
- 弱い所: 児童数・生徒数は2015年の値で、並べただけで、そこから言えることはまだ無い
- 那珂川市は、いまのコードに値が無く、前の那珂川町のコードから取れた(11/16。17市町すべてで値が返った)
- 別の目での点検(11/16)を受けて、公開データの `areaServed` の URI から出発する形に直した。点検の結果は `docs/公開の形.md` の末尾
