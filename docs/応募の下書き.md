### 作品の概要説明(案)

不登校の子どもと保護者が使える公的な支援は、市町村ごとに違います。このデータは、福岡県の市町村について、フリースクール等の利用料の補助、教育支援センター、学びの多様化学校、オンラインの支援、出席扱いの要綱の5種類を同じ項目で並べ、1件ごとに公式の出典と確認日を付けたものです。

いちばんの特徴は、「制度なし」と「確認できず」を混ぜないことです。公式サイトに記載が無いとき、制度が無いのか、載っていないだけなのかは分かりません。このデータでは、市町村の回答か公式の一覧で確かめられたものだけを「なし」とし、見つからなかっただけのものは「確認できず」として、探したページの URL を残します。

「あり」の行は、金額や対象に出てくる数字が出典のページに実際にあるかをプログラムで照合し、合わない行は公開しません。週に1回、出典のページを取り直し、変わった所を記録します。

132件(あり・予定 26、なし 54、確認できず 52)を、CSV、JSON-LD、Turtle で公開しています。1件ごとに URI があり、市町村は e-Stat 統計LOD の標準地域コードにつないでいます。無い・分からないという記録を、制度として数えさせないよう、型を分けています。分かっていないことも、作品のページに書いています。

## URL の選び方

フォームの URL は、審査する人が最初に開くページ。入口の表(`/`)は保護者向けで、作品の説明が無い。そこで「この作品について」(`about/`)を作った。課題、いまの中身(数はデータから数える)、正しさを保つ仕組み、使い方、分かっていないことが1ページで読める。表・データ・リポジトリへは、そこから行ける。

## 審査の観点と、いま示せるもの

| 観点 | 示せるもの | 弱い所 |
|---|---|---|
| 影響力 | 「無い」と「分からない」を分ける決まりと、探した場所の記録 | 使った人、直してくれた市町の事実がまだ無い |
| 創造力 | 無い・分からないを「確かめた記録」として持ち、制度とは型を分ける。検査で保存を止める | |
| 有用性 | 市町×種類の表、1件のページ(出典、確認日、確かめ方) | 「確認できず」が52件。福岡都市圏の85マスでは51 |
| 機械可読性 | CSV、JSON-LD、Turtle。1件ごとの URI。言語つきの文字列。語彙の説明。公開後に全件の URI を引いて確かめる | 303 と形式の出し分けは無い(GitHub Pages) |
| 開放性 | データは CC BY 4.0、プログラムは MIT。リポジトリで作り方を公開 | |
| つながる可能性 | 市町村は e-Stat の標準地域コード。出典は公式ページへ | **ほかの作品で使われた事実が無い。**法令、学校コードにはつないでいない |
| 持続可能性 | 週1回の取り直し、変わった所の記録、知らせ。検査とテスト。手順はほかの県に広げられる | 取り直しは、まだ1回しか回っていない。直すのは1人 |

## 送るまでにやること

1. 問い合わせの回答を入れ、「確認できず」を減らす(いちばん効く)
2. 人の再確認を進め、誤りの割合を出す
3. つながる可能性: ほかの作品で、このデータを実際に使う(下)
4. 応募者名と所属を決める
5. 公式サイトで、テーマ賞とパートナーの資源を確かめる(要項のページには無かった)
6. 送る直前に、概要説明の数を `about/` に合わせる。送った後は、1/5 まで中身を直せる

## つながる可能性について(橋本に相談)

観点の説明は「複数のデータの組み合わせが提案され、ほかの作品などで利用・実現されているか」。いま示せるのは、つないだ先だけで、使われた事実が無い。データ活用部門に出す「わたしの学校2050」が、このデータを1か所でも読んで使えば、2つの作品が互いの裏付けになる。使えるかどうかは、向こうの設計しだいで、こちらでは分からない。
