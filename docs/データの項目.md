# データの項目

`data/seido.csv` の1行は「1市町村の1制度」。文字コードは UTF-8。

## 項目

| 列 | 中身 | 決まり |
|---|---|---|
| id | `市町村コード-種類` | 例: `40219-fs-hojo`。同じ市町村に同じ種類が複数あれば `-2` を付ける |
| 市町村コード | 5桁の標準地域コード | 県の行は `40000`。`data/shichoson.csv` にあるコードだけ。名前も台帳と合わせる |
| 市町村 | 名前 | |
| 制度の種類 | 下の6つのどれか | |
| 補助の形 | 毎月 / 利用開始時の1回 / 年度ごと / その他 | 利用料の補助が「あり」「予定」のときは必須 |
| 状態 | あり / 予定 / なし / 確認できず | 下の「状態の決まり」 |
| 制度名 | 公式の名前 | 「あり」「予定」のときは必須 |
| 対象 | だれが使えるか | 140字まで。文章を写さず、要点に直す |
| 金額 | 金額の決まり | 140字まで |
| 上限額_円 | 上限の金額 | 円の整数。カンマなし。この数字が根拠の箇所の中に無いと保存できない |
| 補助率 | 補助の割合 | `1/2` の形 |
| 開始 | いつから | 開始の時期だけを書く。要綱の制定日などは備考へ |
| 出典URL | 公式ページの URL | 公式サイトのドメインだけ |
| 出典名 | ページの呼び名 | |
| 根拠の箇所 | 出典のページにある短い語句 | 40字まで。「あり」「予定」のときは必須。照合に使う |
| 要綱の状況 | 取得済み / リンクあり・URL未取得 / ページにリンクなし / 空 | |
| 要綱URL | 要綱の URL | 「取得済み」のときだけ入る |
| 探した場所 | 探したページの URL | 「確認できず」のときは必須。複数は ` \| ` で区切る |
| なしの根拠 | 無いと言える理由 | 「なし」のときは必須。問い合わせの日付と担当課、または公式の資料 |
| 備考 | 補足 | 140字まで |
| 確認日 | 確かめた日 | `YYYY-MM-DD` |
| 確認方法 | 機械の読み取り / 人の再確認 / 問い合わせ | |

## 制度の種類

| id に使う名前 | 種類 |
|---|---|
| fs-hojo | フリースクール等の利用料の補助(保護者向け) |
| shien-center | 教育支援センター(校外) |
| tayouka | 学びの多様化学校 |
| online | オンラインでの公的な支援 |
| shusseki | 出席扱いの要綱・施設一覧の公表 |
| fs-unei | 施設への補助(設置者向け) |

`fs-unei` は、保護者が申請する制度ではない。保護者向けの補助と混同されやすいので別の種類にしてあり、県の行にだけ使える。

## 状態の決まり

| 状態 | 保存できる条件 |
|---|---|
| あり / 予定 | 出典URL、根拠の箇所、確認日、制度名がそろっている |
| なし | 「なしの根拠」がある。機械の読み取りで「なし」とするなら、無いと分かる公式の資料の URL と、その資料を示す根拠の箇所が要る。制度名・金額・開始は空でなければならない |
| 確認できず | 「探した場所」がある。制度名・金額・開始・出典URL・根拠の箇所は空でなければならない |

公式ページで見つからなかっただけのものを「なし」と書かない。

## 公式サイトのドメイン

次のどれかに当てはまる URL だけを出典にできる。

1. `lg.jp`(地方公共団体)、`go.jp`(国)
2. 福岡県内の地域型ドメイン: `pref.fukuoka.jp`、`city.◯◯.fukuoka.jp`、`town.◯◯.fukuoka.jp`、`vill.◯◯.fukuoka.jp`
3. 上に当てはまらない公式サイトは、確かめた根拠と一緒に `data/koushiki_domain.csv`(列: ドメイン、市町村、根拠)に足す

## 照合

「あり」「予定」の行は、出典のページを取りに行き、次の2つを確かめる。

1. 根拠の箇所が、ページの文字列にそのままある
2. 金額・対象・開始・上限額・補助率に出てくる「数字と単位」が、ページにもある

表記のゆれはそろえてから比べる。

| そろえるもの | 例 |
|---|---|
| 全角と半角、カンマ、空白 | `１０，０００円` = `10000円` |
| 万・千 | `3万円` = `30,000円` |
| 分数 | `2分の1` = `二分の一` = `1/2` |
| 元号と西暦 | `令和7年度` = `2025年度` |

## 「なし」の照合

出典が、設置校などを並べた公式の一覧であるとき、「なし」もコードで照合する。

1. 根拠の箇所がページにある(狙った一覧のページであること)
2. 「県名+市町村名」がページに出てこない

いまは、学びの多様化学校を、文部科学省の設置者一覧と突き合わせるのに使っている。分かるのは「一覧に載っていない」ことまで。

## 公開データに入るまで

1. 読んだ結果を `data/kouho.csv`(候補)に入れる。この時点で読み込み時の検査に通らなければならない
2. GitHub Actions の `shougou` が、候補の出典ページを取りに行って照合する
3. 一致した行だけを `data/seido.csv` に移す(`scripts/furiwake.py`)。合わない行は `data/horyu.csv` に理由つきで回す

取得は robots.txt に従う。robots.txt を確かめられないサイトには取りに行かない。

照合で分かるのは「ページに無い数字を載せていない」ことまで。数字の意味の取り違えは、検証役と人の再確認で見る。
