# 市町への問い合わせ

このファイルは `scripts/toiawase.py` がデータから作る(2026-11-16 時点)。11/17 に、送った後の記録(福岡市の4問目、電話の手がかり)を手で足した。送った文面を残すため、作り直さない(作り直すと、その後「あり」になった質問が文面から消える)。

公式サイトを読んでも分からなかったことを、市町に聞く。目的は、「確認できず」を「あり」か「なし」に変えること。「なし」は、市町が無いと答えた記録があって初めて書ける。

いま聞くことは、福岡都市圏の17市町で合わせて55問(11/17 に、福岡市へ1問足した)。都市圏の外では、大牟田市へ学びの多様化学校について3問を送った(11/17)。

## 文面(メール・問い合わせフォーム用)

件名は「不登校支援の制度についての問い合わせ(◯点)」。本文は、下の「市町ごとの文面」にある(氏名と連絡先だけ入れる)。

文面の決まり

- 短くする。名乗り、何のためか(1文と公開ページの URL)、質問、回答を載せることの断り、だけ
- 質問は「ある」「ない」で答えられる形にする
- 回答を担当課名つきで載せることは、必ず書く。応募する大会の名前や、ライセンスは書かない
- 返事の目安を書く

## 電話で聞くとき

1. 名乗る: 「福岡市に住んでいる◯◯です。県内の市町村の不登校支援の制度を一覧にするオープンデータを作っています」
2. 質問を1つずつ聞く。「ある」「ない」「分からない」を聞き分ける。「分からない」「担当が違う」は「なし」にしない
3. 「ある」なら、制度名と、載っているページや要綱の場所を聞く
4. 最後に、回答を担当課名つきで公開データに載せる予定だと伝え、差し支えがあるかを聞く
5. 切ったらすぐ、日付・担当課・回答を `data/toiawase.csv` に書く

### 電話の順番と、聞くときの手がかり(11/17)

- **11/17 午後の決定: 利用料の補助と、出席扱いの決まりを先に聞く。** 時間が限られるときは、この2つだけでよい。公式ページで見つからないことが多い所で、回答がデータの主役になる
- 市町の順番の目安は(聞く種類を上の2つに絞ったうえで)、公開ページの「組み合わせの例」の「隣り合う市町と並べる」の表(隣の市町村で同じ種類が「あり・予定」のマス)。上から聞く
- 11/17 に、その表のマスを種類の語で市町のサイト内を検索した。新しく「あり」にできるものは無かった。公式の説明ではないが、聞くときに名前を出せる手がかりが3つあった(各行の備考と探した場所に記録した)
  - 宇美町: 総合計画の素案に「適応指導教室(くすのき教室)」。学校の外の教室か、いまもあるか
  - 篠栗町: 議会の答弁に「教育支援センターをオアシスに広げる」。子どもが通う教室か(相談窓口だけか)
  - 粕屋町: 教育相談室「ぽると」のサポートルーム。子どもが日中に通って過ごせる場か(相談だけか)

## 回答の記録と、データへの反映

- 記録は `data/toiawase.csv`。列: 日付、市町村コード、市町村、担当課、方法(電話/メール/フォーム)、種類、回答、公開の可否、反映した id
- 担当の方の個人名は書かない
- 回答の列は「ある」「ない」「公表していない」「分からない」のどれかで始め、補足を項目に直して続け、最後に「(回答日 2026-11-18)」の形で回答日を書く。公開ページはこの頭の語と回答日で出し分ける(11/21)。日付の列は送った日のまま。担当課の列は、回答があったら答えた課(署名)に書き換える
- 「ある」と答えてもらえたが、公式の案内ページが無い(学校を通じてだけ案内している、など)ものは、状態を「確認できず」のままにし、公開ページで「ある」と答えたことを添える。「あり」は公式の出典が要るので、ページか要綱の場所を聞き続ける(11/21。新宮町の教育支援センターとオンライン、久山町の教育支援センター)
- 載せ方の頼みがあれば、公開の可否の列に書く(新宮町: 案内ページの無い2つに「各学校へ相談」の文言を添える)
- 「公表していない」は、出席扱いの項目では「なし」に当たる(項目は「公表」を見ている)。公開ページでは、出席扱いにならないという意味ではないことを添える
- 「ない」と答えてもらえた種類は、状態を「なし」にし、「なしの根拠」に「日付・担当課・方法」を書く。確認方法は「問い合わせ」
- 「ある」と答えてもらえた種類は、教わったページを読んで「あり」の候補にし、照合に通す。ページが無い制度は、要綱の場所を聞く
- 回答が無い、分からないと言われた種類は「確認できず」のまま。備考に、問い合わせた日を書く
- 「載せることに差し支えがある」と言われたときは、回答をデータに使わず、「確認できず」のままにする。公開の可否の列に「差し支えあり」と書く
