# 不登校支援制度LOD

市町村ごとに違う不登校支援の制度を、同じ項目で並べ、公式の出典と確認日を付けて公開するデータ。対象は福岡県の市町村。LODチャレンジ2026(データ作成部門)に出す。

いちばん大事にしている決まりは一つ。**「制度なし」と「確認できず」を混ぜない。**

## 対象の範囲

義務教育の段階(小学生・中学生)に向けた、市町村の制度を対象にする。根拠の法律(義務教育の段階における普通教育に相当する教育の機会の確保等に関する法律)の範囲に合わせている。

高校生に向けた支援(高校の学びの多様化学校、定時制・通信制など)は、主に県や学校法人が担うもので、市町村ごとに並べるこのデータには入れていない。

| 状態 | 意味 |
|---|---|
| あり / 予定 | 公式の出典、根拠の箇所、確認日がそろっている |
| なし | 市町村が「無い」と答えた記録か、無いと分かる公式の資料がある |
| 確認できず | 公式ページで見つからなかっただけ。無いとは言っていない |

「確認できず」が多いのは、まだ各市町で1〜数ページしか読んでいないため。見つからなかっただけで、制度が無いという意味ではない。探したページは各行の「探した場所」にある。

学びの多様化学校の「なし」は、文部科学省の設置者一覧に、その市町村を設置場所とする学校が載っていないという意味。設置の検討や予定は、この一覧からは分からない。

```
pip install -r requirements-dev.txt
python -m futoko_lod.schema data/seido.csv   # 検査
python -m futoko_lod.build                   # JSON-LD を作り直す
python -m pytest -q                          # テスト
python -m futoko_lod.fetch data/seido.csv    # 出典を取りに行って照合(間隔をあけて取得する)
```

## 分かっていないこと

- **福岡市・北九州市に、保護者向けの利用料補助があるかどうか。** 公式ページに記載が見つからなかっただけで、無いことは確かめていない。
- **公開データが正しいかどうか。** 人の再確認をしていない。大野城市の出席扱い一覧(`40219-shusseki`)は、読み取りの道具でページを開けず、最初の試し読みの内容を引き継いだ。照合で確かめたのは一覧の時点を示す語句だけなので、再確認を先にする。
- **残りの市町村。** 福岡都市圏では、須恵町の出席扱いと、古賀市の2種類(オンライン、出席扱い)が未着手。都市圏の外は、学びの多様化学校のほかは、ほぼ未着手。
- **小郡市の学びの多様化学校。** 文部科学省の一覧に、小郡市にある県立高校が載っている。このデータは小中学生向けの市町村の制度が対象なので、一覧の名前の有無だけでは「なし」と書けない。未着手のままにしている。
- **種類の境目にある行。** 粕屋町の教育相談室「ぽると」は、資料に「教育支援センター」の語が無い。学校に行けない児童生徒のためのサポートルームがあるので、教育支援センターの種類に入れた。篠栗町の教育支援センターは、相談窓口の一覧に名前があるだけで、通う教室があるかは確かめていない。
- **「確認できず」の深さ。** 不登校支援のページと、そこから辿れる資料を読んだだけの市町が多い。例規集や議会の資料までは探していない。
- **須恵町の適応指導教室。** 対象や費用は、町の案内資料(PDF)を読んで項目にした。出典には、その資料が載っている町のページを書いている。照合で確かめたのは、教室の名前がそのページにあることまで。資料そのものの URL は記録していない。
- **学びの多様化学校の開校の時期。** 大野城市と宇美町は、開校の時期を項目に入れていない(出典のページに記載が無いため)。文部科学省の一覧にある指定年は、備考に書いた。
- **つなぐ先の URI のうち、学校コードと法令。** 文部科学省の学校コードの URI の書式は確かめていない。根拠の法律(法令ID `428AC1000000105`)は、e-Gov の法令API で引けることまで確かめたが、データにはまだつないでいない。法令のページの URL の書式は、公式の説明に記載が見つかっていない。
- **このデータ自身の URI。** JSON-LD の `@id` と語彙(`fsl:`)は仮のもの。固定の URL を決めるときに変わる。
- **照合の限界。** 照合は「ページに無い数字を載せない」ための網で、数字の意味の取り違え(たとえば上限額と補助額)までは見つけられない。
- **要綱の URL。** 「リンクあり・URL未取得」の行は、要綱の PDF の場所をまだ記録していない。県の交付要綱は記録した。
- **福岡市の学びの多様化学校の出典。** 最初に出典にした資料には、学びの多様化学校であることと開校の時期が書かれていなかった。市教育委員会のページに出典を替えた。
