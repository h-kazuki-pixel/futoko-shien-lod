# 不登校支援制度LOD

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24292049.svg)](https://doi.org/10.5281/zenodo.24292049)

市町村ごとに違う不登校支援の制度を、同じ項目で並べ、公式の出典と確認日を付けて公開するデータ。対象は福岡県の市町村。LODチャレンジ2026(データ作成部門)に出す。

いちばん大事にしている決まりは一つ。**「制度なし」と「確認できず」を混ぜない。**

公開の場所: https://h-kazuki-pixel.github.io/futoko-shien-lod/ (市町×種類の表、1件ごとのページ、CSV・JSON-LD・Turtle)

## 対象の範囲

調べる深さは、2段にしている。

- **福岡都市圏の17市町**: 5種類すべてを、公式サイトの読み取りと、市町への問い合わせで確かめる。
- **県内の60市町村**: 学びの多様化学校(国の一覧と突き合わせる)と、県の制度だけ。

広く薄く並べるより、17市町で「確認できず」を減らすことを先にする。残りの市町村へは、同じ手順で広げられる。

義務教育の段階(小学生・中学生)に向けた、市町村の制度を対象にする。根拠の法律(義務教育の段階における普通教育に相当する教育の機会の確保等に関する法律)の範囲に合わせている。

高校生に向けた支援(高校の学びの多様化学校、定時制・通信制など)は、主に県や学校法人が担うもので、市町村ごとに並べるこのデータには入れていない。

| 状態 | 意味 |
|---|---|
| あり / 予定 | 公式の出典、根拠の箇所、確認日がそろっている |
| なし | 市町村が「無い」と答えた記録か、無いと分かる公式の資料がある |
| 確認できず | 公式ページで見つからなかっただけ。無いとは言っていない |

## 使い方

```
pip install -r requirements-dev.txt
python -m futoko_lod.schema data/seido.csv   # 検査
python -m futoko_lod.build                   # JSON-LD を作り直す
python -m futoko_lod.shapes                  # 形(SHACL)を作り直す
python -m futoko_lod.publish && python -m futoko_lod.shapes --validate _site   # 公開の一式を書き出して、形で検査
python -m pytest -q                          # テスト
python -m futoko_lod.fetch data/seido.csv    # 出典を取りに行って照合(間隔をあけて取得する)
```

## 分かっていないこと

- **福岡市・北九州市に、保護者向けの利用料補助があるかどうか。** 公式ページに記載が見つからなかっただけで、無いことは確かめていない。
- **公開データが正しいかどうか。** 「あり」「予定」の33件(147項目、`data/saikakunin.csv`)のうち、人が出典と見比べたのは108項目で、「違う」は無かった。全項目を人が見た制度は22件。残りの39項目は、人はまだ見ていない。読む役とは別の呼び出しと、別の会社のモデルでも見比べた(`docs/検証の結果.md`)。見比べたのは橋本1人で、データを作った側でもある。
- **残りのマス。** 福岡都市圏では、須恵町の出席扱いだけが未着手。
- **小郡市の学びの多様化学校。** 文部科学省の一覧で設置場所が小郡市なのは、県立高校のコースだけ。市が管理する学校が載っていないことを確かめて「なし」にした(2026-11-16)。一覧からは、設置の検討や予定は分からない。
- **種類の境目にある行。** 粕屋町の教育相談室「ぽると」のサポートルームと、篠栗町の教育支援センターは、資料から「通う教室」と読み取れなかったので「確認できず」にした。町に問い合わせている。
- **「確認できず」の深さ。** 不登校支援のページと、そこから辿れる資料を読んだだけの市町が多い。例規集や議会の資料までは探していない。
- **須恵町の適応指導教室。** 11/15 は町の robots.txt の指定で、機械では取得しなかった。11/16 夜の照合では robots.txt が無く(HTTP 404)、出典のページと案内資料(PDF)を機械で取得して、照合は両方で一致した。robots.txt が戻れば、また機械では取得しない。対象や費用は、人が案内資料と見比べて確かめた(2026-11-16)。照合が見るのは根拠の語句までで、対象や費用の文の意味までは見ていない。
- **学びの多様化学校の開校の時期。** 義務教育の段階の「あり」「予定」は5行(宇美町は2つの分校で1行)。2026-11-17 に、大野城市(県の設置廃止等一覧)と宇美町(県のサイトにある学校の概要の資料)の開始を入れ、5行のうち4行に開始がある。照合で一致したが、人はまだ見ていない。大牟田市は、学びの多様化学校としての開始が分からず、空のまま(夜間中学としての開始は備考にある)。
- **大牟田市のほしぞら分校の対象。** 文部科学省の一覧では学びの多様化学校で、同時に夜間中学でもある。学齢の不登校の子どもがどう通えるか(時間帯、入学の条件)は確かめていない(`docs/弱い所.md` の37)。
- **形(SHACL)で見られない決まり。** 公開する RDF の決まりは `shapes.ttl` に書き、公開のたびに検査している。ただし、id と市町村コードの前半が合うこと、金額などが出典のページにあることなどは形では書けず、CSV の検査と照合で見ている(`docs/公開の形.md` の「形(SHACL)」)。形を確かめた道具は pySHACL だけ。
- **つなぐ先の URI のうち、学校コードと法令。** 文部科学省の学校コードの URI の書式は確かめていない。根拠の法律(法令ID `428AC1000000105`)は、e-Gov の法令API で引けることまで確かめたが、データにはまだつないでいない。法令のページの URL の書式は、公式の説明に記載が見つかっていない。
- **このデータ自身の URI。** 土台は GitHub Pages の公開の場所に決めた(2026-11-15)。GitHub Pages では、もの(制度)の URI とページを分ける転送(303)や、形式の出し分けはできない。データは URI に `.ttl` か `.jsonld` を付けて取る(`docs/公開の形.md`)。
- **照合の限界。** 照合は「ページに無い数字を載せない」ための網で、数字の意味の取り違え(たとえば上限額と補助額)までは見つけられない。
- **要綱の URL。** 「リンクあり・URL未取得」の行は、要綱の PDF の場所をまだ記録していない。県の交付要綱は記録した。
- **福岡市の学びの多様化学校の出典。** 最初に出典にした資料には、学びの多様化学校であることと開校の時期が書かれていなかった。市教育委員会のページに出典を替えた。
