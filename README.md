# 不登校支援制度LOD

市町村ごとに違う不登校支援の制度を、同じ項目で並べ、公式の出典と確認日を付けて公開するデータ。対象は福岡県の市町村。LODチャレンジ2026(データ作成部門)に出す。

いちばん大事にしている決まりは一つ。**「制度なし」と「確認できず」を混ぜない。**

| 状態 | 意味 |
|---|---|
| あり / 予定 | 公式の出典、根拠の箇所、確認日がそろっている |
| なし | 市町村が「無い」と答えた記録か、無いと分かる公式の資料がある |
| 確認できず | 公式ページで見つからなかっただけ。無いとは言っていない |

## いまの状態(2026-11-15)

作り始めたところ。見本の12件を新しい形に入れ直した段階で、市町村の網羅はまだしていない。

| | 件数 | 数え方 |
|---|---|---|
| 公開データ(`data/seido.csv`) | 7 | 読み込み時の検査と、出典ページとの照合に通った行(「確認できず」の2件は照合の対象外) |
| 保留(`data/horyu.csv`) | 5 | 検査に落ちた4件(「あり」なのに根拠の箇所が空)と、照合に落ちた1件(県の設置者向け補助) |

公開データの7件は、機械の読み取りと照合だけで、人の再確認をまだしていない。出典ページとの照合の結果は、GitHub Actions の `shougou` の実行結果で見られる。

## ファイル

| 場所 | 中身 |
|---|---|
| `data/seido.csv` | 公開データ。1行 = 1市町村の1制度 |
| `data/seido.jsonld` | 同じ中身の JSON-LD(`seido.csv` から作る) |
| `data/horyu.csv` | 検査や照合に通らず、人が見る一覧に回した行。公開データではない |
| `data/pilot/` | 最初の試し読みの見本(元のまま) |
| `docs/データの項目.md` | 項目の意味と、検査の決まり |
| `futoko_lod/` | 検査、照合、取得、JSON-LD の生成 |

## 使い方

```
pip install -r requirements-dev.txt
python -m futoko_lod.schema data/seido.csv   # 検査
python -m futoko_lod.build                   # JSON-LD を作り直す
python -m pytest -q                          # テスト
python -m futoko_lod.fetch data/seido.csv    # 出典を取りに行って照合(間隔をあけて取得する)
```

## 分かっていないこと

- **福岡市・北九州市に、保護者向けの利用料補助があるかどうか。** 公式ページに記載が見つからなかっただけで、無いことは確かめていない。
- **公開データの7件が正しいかどうか。** 人の再確認をしていない。
- **保留の5件。** 4件は根拠の箇所を出典のページから取り直す必要がある。1件(県の設置者向け補助)は、金額の出どころの資料を取り直す必要がある。
- **残りの市町村。** まだ読んでいない。
- **市町村コード。** 見本のコードを、公式の資料とまだ突き合わせていない。
- **つなぐ先の URI。** e-Stat 統計LOD(標準地域コード)、e-Gov 法令検索、文部科学省の学校コードの URI の書式は、公式の説明で確かめるまで入れない。
- **このデータ自身の URI。** JSON-LD の `@id` と語彙(`fsl:`)は仮のもの。固定の URL を決めるときに変わる。
- **照合の限界。** 照合は「ページに無い数字を載せない」ための網で、数字の意味の取り違え(たとえば上限額と補助額)までは見つけられない。
- **要綱の URL。** 「リンクあり・URL未取得」の行は、要綱の PDF の場所をまだ記録していない。
